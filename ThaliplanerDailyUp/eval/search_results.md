# ThaliPlanner Semantic Search Results

This report is generated by the S1 semantic evaluation script. It is populated
with actual retrieved chunks, similarity scores, source, page, and title when
you run:

```bash
python -m app.embed
```

Do not manually invent or pre-fill retrieval scores. The script reads the
10 questions from `eval/questions.md`, embeds the project documents, runs
semantic search for each question, and writes the actual top-5 hits here.
