# ThaliPlanner

## Project Card

- Product:ThaliPlanner – a Travel & Culture discovery concept.
- User: Travellers and people interested in exploring Indian food, destinations, festivals, and traditions.
- Problem: Travellers often need to search different places to learn about regional thalis, local traditions, festivals, and cultural experiences. ThaliPlanner brings these discovery ideas together in one place.
- Data source: Public tourism information, regional food and thali descriptions, festival and cultural information, and sample data prepared for this project. Information will be checked before being used in a production version.

 Day 01

- `day01_intro.py` prints the project card using variables and f-strings, then asks the user for their name and a question.
- `day01_menu.py` provides a while-loop menu with project information, sample questions, a simple regional-food rule, and an exit option.

## Run the programs

```bash
python day01_intro.py
python day01_menu.py
```
